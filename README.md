# 🤖 Projeto Python IA – Previsão de Score de Crédito

Este projeto utiliza Python e técnicas de Inteligência Artificial / Machine Learning para criar um modelo capaz de prever automaticamente o score de crédito de clientes de um banco.

Com base em dados históricos, o modelo classifica cada cliente em três categorias de risco: Ruim, Ok ou Bom, auxiliando na tomada de decisão financeira.

## 🚀 Funcionalidades

Importa e carrega a base de dados de clientes (clientes.csv)

Realiza o pré-processamento dos dados, convertendo variáveis categóricas em valores numéricos

Define variáveis preditoras (features) e variável alvo (score de crédito)

Treina modelos de Machine Learning para classificação

Avalia o desempenho dos modelos utilizando métrica de acurácia

Realiza previsões de score de crédito para novos clientes

## 🛠️ Tecnologias Utilizadas

Python 3

Pandas – manipulação e análise de dados

Scikit-learn – criação, treinamento e avaliação de modelos de Machine Learning

RandomForestClassifier – modelo baseado em árvores de decisão

KNeighborsClassifier (KNN) – modelo baseado em vizinhos mais próximos

## 📚 Aprendizados

Pré-processamento de dados para Machine Learning

Codificação de variáveis categóricas

Criação e comparação de modelos de classificação

Avaliação de modelos com métricas de desempenho

Aplicação prática de Inteligência Artificial em problemas de negócio

## 📈 Resultados do Projeto

Após a avaliação dos modelos:

Random Forest apresentou melhor desempenho em relação ao KNN

O modelo final foi utilizado para prever o score de crédito de novos clientes

O sistema é capaz de classificar automaticamente os clientes em Ruim, Ok ou Bom, tornando o processo de análise mais rápido e eficiente.
